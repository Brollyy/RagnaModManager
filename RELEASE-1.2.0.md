# RagnaModManager 1.2.0

## Mod workflow

- Actionable dependency warnings with install, update, and enable actions.
- Searchable installed and official libraries.
- Select-all/none plus bulk enable, disable, and removal.
- Update-all support, dashboard update count, and registry check status.
- Rich mod manifest details, package sizes, release notes, and registry metadata.
- Drag-and-drop `.rmod` importing.

## Profiles and recovery

- Profiles can be exported, imported, cloned, and version-pinned.
- Missing profile mods are visible with a removal action.
- Deployment previews show file/conflict counts.
- Rollback and managed-deployment reset are available in Settings.

## Launching and compatibility

- Saved launch arguments are available in Settings.
- Semantic-version ordering supports prereleases.
- Manager compatibility version is now 1.2.0.

Multiple Ragnarock installations remain out of scope for this release.
